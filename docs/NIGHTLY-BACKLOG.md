- [x] 2026-08-21 → 2026-08-21 — **`archiveMove` overwrote an existing archived record** — found and fixed in one run, recorded here so a future run reading `retention.mjs` does not re-derive it. The "archive never delete" module used a plain `copyFileSync` into a flat namespace keyed by the caller-supplied `task_id`; `startTask`'s exclusive-create guard only covers the *live* working-memory file, so reusing an id after retention archived it destroyed the first task's only copy.
