- [ ] 2026-08-20 — **One fail-closed `requireAuth()` chokepoint for the web write routes** — auth is currently re-implemented per route and fails *open*. `/api/process`, `/api/compile` and `/api/lint` gate on `if (PRIVATE_PIN && !pinMatches(...))`, so an unset `PRIVATE_PIN` means no auth on routes that spend the Anthropic key and write the wiki — while the read routes (`/api/search`, `/api/article`) correctly treat an unset PIN as "private disabled". Worse, these have **no check at all**: `POST /api/agents/promote`, `POST /api/agents/bus/[channel]`, `POST /api/ingest`, `POST /api/repos`, `POST /api/repos/[repo]/sync`, `POST /api/process/run-all`, and both `close-task` routes. `resolveIdentity` in `lib/agent-runtime/identity.mjs` compounds it: the `X-Identity-Kind`/`X-Identity-Id` and `X-Agent-Id` branches are unverified *and* are checked before the bearer-token branch, so any caller can name themselves `sofie` and have that id signed into the audit chain. There is no `middleware.ts`. Patching routes one at a time is how this became nine routes; the fix is a single helper plus a test that enumerates every non-GET handler.

- [ ] 2026-08-20 — **Retire the regex denylist in `scripts/hooks/pre-commit` for a real secret scanner** — the hook's whole deny-list is PII patterns; it has *no* pattern for API keys, tokens, PATs or passwords, so `ANTHROPIC_API_KEY=sk-ant-…`, `ghp_…` and `AKIA…` all commit cleanly through it. Meanwhile the PII half is on a treadmill: `69917a6d` (PII guard silently disabled the Rule 13 vault guard), `42b14fcf` (therapy patterns loosened to unblock a public quote), `3afe01c5` (unjam a raw/ PII deadlock that blocked 41 Refinery runs) — three loosening commits in five days, and the one real credential leak of the period (`f0a12403`, a bearer-token prefix persisted into committed frontmatter) sailed past it and had to be fixed in application code. Structural bypasses: the scan uses `--diff-filter=AM`, so a `git mv` carries staged PII through untouched; base64 defeats it entirely; and `core.hooksPath` is unset in a fresh clone so it does not run at all. Proposal: `gitleaks`/`trufflehog` over `--diff-filter=ACMRT` with an allowlist file, keep only the vault-path guard as bespoke logic, and make installation part of `npm ci`. **Do not add pattern #25.**

- [ ] 2026-08-20 — **Escape the JS heredoc in `scripts/team-setup.sh`** — lines 341-365 interpolate `$PRIVATE_PIN`, `$KB_DIR`, `$WIKI_DIR` and `$OPENAI_API_KEY` directly into JavaScript source piped to `node`. Any of those values can close the string literal and execute arbitrary code; the values come from interactive `read -r` prompts and the script advertises a `curl … | zsh` install. Pass them via `process.env` or `process.argv` instead of string interpolation. Related, same file: `PRIVATE_PIN="${PRIVATE_PIN:-changeme}"` persists a guessable default into `web/.env.local`, the LaunchAgent plist, and the Claude Desktop MCP config.

- [ ] 2026-08-20 — **Raise the PIN work factor in `scripts/pin.mjs`, and treat the committed `.enc` blobs as already exposed** — the construction is sound (AES-256-GCM, per-file random salt and IV, auth tag verified, tmp+rename), but `PBKDF2_ITER = 100_000` SHA-256 with a 4-character minimum is not a work factor. Measured in this sandbox at ~116 guesses/sec/core, the entire 4-digit keyspace falls in about 86 seconds. `wiki/_private/.enc/stuck-on.md.enc` and `next-milestone.md.enc` are **committed to a public repo**, so this is an offline attack on anyone who clones. Switch to scrypt or argon2id, enforce a real minimum length, and re-lock every blob under a new PIN.

- [ ] 2026-08-20 — **`atomicWrite` is copy-pasted nine times and none of the copies fsync** — `writeback.mjs:228`, `repo-runtime/writeback.mjs:20`, `retention.mjs:13`, `sync.mjs:205`, `vault-writeback.mjs:42`, `promotion.mjs:41`, plus inline copies in `bus.mjs`, `repo-runtime/bus.mjs`, `registry.mjs` and `task-lifecycle.mjs`. All are `writeFileSync(tmp)` + `renameSync`. Without an fsync on the file and on the containing directory, a power loss can make the rename durable while the data blocks are not — strictly worse than a plain overwrite for the "must never leave a truncated registry.json" goal the code states. None of them unlink the tmp file if the rename throws, so an ENOSPC leaves `.tmp-…` orphans that `walkDocs`/`walkDir` filter out (they match `.md`) but git and Obsidian do not. One shared helper in `lib/agent-runtime/atomic.mjs`.
