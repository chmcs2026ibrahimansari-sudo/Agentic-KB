## TL;DR

OOMOL claims OpenConnector is an open-source, self-hostable, MCP-native connector layer for 1,000+ apps that keeps credentials in a gateway and gives agents scoped access plus safe results instead of raw API keys.

## Key Points

- The tweet warns against handing raw API keys to AI agents.
- It proposes a gateway that holds credentials and exposes scoped access to agents.
- OOMOL describes OpenConnector as open-source, self-hostable, MCP-native, and covering 1,000+ apps.
- This matches the broader [[patterns/pattern-sandbox-auth-proxy]] security pattern: agent-visible code should not hold long-lived secrets directly.

## Reusable Ideas for Agentic-KB

- Treat connector gateways as credential boundaries, not just convenience integrations.
- MissionControl/Hermes tool access should prefer scoped, auditable, revocable credentials at the gateway/tool layer over model-visible API keys.
