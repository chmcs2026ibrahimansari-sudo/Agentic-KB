## TL;DR

This social capture presents MCP as the standard protocol layer for connecting agents to tools, resources, and prompts, with claims about 2026 stateless MCP, enterprise authorization, production security practices, and complementary A2A agent-to-agent coordination.

## Key Points

- **MCP role model:** The source explains the host/client/server split: host is the app users interact with, client lives inside the host, and server exposes capabilities.
- **Three primitives:** Tools are callable functions, resources are readable data/context, and prompts are reusable templates.
- **Production security advice:** The source recommends auth on every production server, input validation for model-generated tool arguments, least privilege, precise tool descriptions, rate limiting, and invocation logging.
- **Protocol claims:** The embedded article claims a July 28, 2026 spec revision introduced a stateless core, extensions, and Enterprise Managed Authorization. This Refinery run did not verify those claims against primary MCP specs.
- **Ecosystem framing:** The source frames MCP as agent-to-tool and Google's A2A as agent-to-agent, complementary rather than competing.
- **Adoption numbers:** Claims such as 400M monthly SDK downloads and 10,000+ servers are preserved as source claims only.
